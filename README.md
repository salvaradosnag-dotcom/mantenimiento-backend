# Mantto Lite PWA

Aplicación web simple tipo MaintainX, optimizada para iPhone y Android.

## Qué incluye
- Dashboard móvil
- Órdenes de trabajo
- Estados, prioridad, responsable, fecha y costo
- Checklists por orden
- Configuración de locales y técnicos
- Exportar e importar JSON
- Funciona offline luego de la primera carga
- Instalable como app en pantalla de inicio

## Cómo publicarla gratis

### Opción 1: Netlify Drop
1. Entra desde iPhone, Android o computador a Netlify Drop.
2. Sube el contenido de esta carpeta o el ZIP.
3. Netlify te entregará una URL pública inmediata.
4. Abre esa URL en Safari o Chrome.
5. En iPhone: Compartir > Agregar a pantalla de inicio.
6. En Android: menú del navegador > Instalar app o Agregar a pantalla principal.

### Opción 2: Vercel
1. Sube la carpeta a un repositorio de GitHub.
2. Importa el repositorio en Vercel.
3. Publica sin configuración adicional.

## Recomendación
Si quieres uso real para varios locales y varios usuarios, el siguiente paso es conectar backend:
- Supabase o Firebase
- Fotos por solicitud
- Usuarios por perfil
- Notificaciones por correo o WhatsApp
